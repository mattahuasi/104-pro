# 💻 Programación I

Repositorio oficial de la materia **Programación I**, correspondiente al primer semestre de la carrera de Ingeniería de Sistemas en la Universidad de los Andes (Unandes).

Este espacio contiene el registro de todo el código desarrollado durante el curso, incluyendo ejercicios de clase, prácticas, exámenes y el proyecto final.

---

### 📂 Contenido del curso

* 📝 **Ejercicios:** Código resuelto durante las sesiones de clase.
* 🛠️ **Prácticas:** Trabajos asignados para reforzar los temas vistos.
* ✍️ **Exámenes:** Resolución de las evaluaciones parciales y finales.
